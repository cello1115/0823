# 專案前釐清目的｜Project Purpose Clarifier

一個輕量的 AI Agent Skill，協助你在新專案開始時，透過簡短對話釐清：**為什麼要做、主要為誰做，以及希望達到什麼效果**。

它適合用於網站、工具、活動、企劃或內容等新方向。使用者已有的資訊不重問；只有答案會改變起步方向時才進一步詢問。當共同理解足以開始，就停止訪談。

## 適合什麼時候使用？

- 有一個新想法，但還不確定目標或主要使用者。
- 想請 AI 幫忙製作工具或網站，希望先對齊用途。
- 不想一開始就填完整需求問卷，只希望先問幾個關鍵問題。

一般問答、現有專案的小修改，或已釐清方向的延續工作，通常不需要啟動。你也可以直接說「跳過，先開始」。

## 如何使用

1. 下載本頁所在的 `skills/project-purpose-clarifier` 資料夾，保留其中的 `SKILL.md`。
2. 依你使用的 AI Agent 文件，將整個資料夾放入它支援的個人或專案 Skill 位置。不同產品與版本的位置可能不同；必要時重新開啟對話。
3. 開始新專案時，可以說：「請使用 project-purpose-clarifier，幫我釐清這個想法。」在支援明確呼叫 Skill 的環境，也可以輸入 `$project-purpose-clarifier`。

你可以用下面的例子開始：

> 我想做一個管理咖啡素材的小工具。請先幫我釐清目的、主要使用者和希望達到的效果；用日常情境提問，知道足夠開始時就停下來。

## 這個 Skill 的想法

這是我在實際與 AI 協作時，為了減少需求模糊和反覆追問而整理的輕量方法。它參考了 [Matt Pocock 的 grilling](https://github.com/mattpocock/skills/blob/main/skills/productivity/grilling/SKILL.md) 等逐步釐清的思路，並把重點放在適合一般專案起步的短對話。

這個 Skill 仍在試用與調整中。不同 AI Agent、模型或任務的表現可能不同，歡迎依自己的工作習慣修改。
